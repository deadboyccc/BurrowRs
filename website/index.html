Your own stealthy Telegram proxy service.

burrowrs runs a Telegram proxy behind a real website with a real certificate, in hardened containers on a server you control. Give everyone one link, or give each user their own, with an expiry date, a data quota and a device limit. Everyone else just finds a quiet personal blog.

Why burrowrs

burrowrs is Burrow, rewritten on a Rust proxy engine, telemt, so that every user can have a secret of their own. Digby came along, in a rust-orange scarf with a cog on it.

🎭

Looks like a website

FakeTLS makes the handshake a TLS 1.3 hello to your own domain. Probes, scanners and browsers get a real site with a Let's Encrypt certificate.

🔑

A key for each user

Names, secrets, expiry dates, data quotas that reset daily, weekly or monthly, device limits and live usage. Changes apply at once, without disconnecting anyone else.

🛡️

Hardened by default

Non-root, read-only, zero-capability containers. Images pinned by digest, dependencies by hash, secrets never in argv or logs, and no access logs.

🩺

Self-healing

Restart policies, Docker live-restore and a watchdog that probes the proxy every five minutes and recreates it if it hangs.

🦀

Light

telemt is a Rust relay with no garbage collector. Idle, it used 5.7 MiB of memory. BBR, fq and tuned buffers help on lossy, long-distance links.

🧪

Tested for real

386 automated tests, including live stacks that push real MTProto traffic to Telegram's data centres, replay and probe attacks, and every user limit.

Two ways to give access

Pick one at install time, switch any time with ./burrowrs config set ACCESS_MODE users.

Shared

One secret, one link, for you and everyone you trust.

  • Share it as a link or an offline QR code.
  • rotate gives everyone a new link at once.
./burrowrs share
./burrowrs rotate

Users

A name and a secret per user: run a small proxy service.

  • Expiry date, data quota with automatic resets, device limit.
  • Renew, disable or rotate one user without touching the others.
./burrowrs user add alice --days 30 \
  --quota 50G --period monthly --ips 2
./burrowrs user list
./burrowrs user renew alice --days 30
./burrowrs user disable bob

How it works

telemt owns port 443. A connection only reaches Telegram if its hello carries an HMAC made with one of your users' secrets, has a fresh timestamp, has never been seen before, and the user is within their limits. Everything else is relayed, byte for byte, to the decoy website.

Get started

About 20 minutes from nothing to your phone using your own proxy. The deployment guide covers every step.

Rent a small server, point a domain at it

1 vCPU, 1 GB RAM, Debian or Ubuntu. Add an A record such as notes.example.com → your server's IP. No domain? Use 203-0-113-7.sslip.io (your IP with dashes).

Run one command on the server

curl -fsSL https://raw.githubusercontent.com/deadboyccc/BurrowRs/main/install.sh |
  sudo BURROWRS_DOMAIN=notes.example.com bash

Add BURROWRS_ACCESS=users for a secret per user. Re-run it any time to upgrade; your secret and users are kept. Prefer your laptop? ./burrowrs deploy root@IP --domain … does the same over SSH.

Scan, connect, share

The installer ends by printing your link and a QR code. Then hand out access: /opt/burrowrs/burrowrs share in shared mode, or /opt/burrowrs/burrowrs user add NAME for each user.
